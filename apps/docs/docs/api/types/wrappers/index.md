# wrappers

<a id="overview"></a>

## Overview

Use wrappers to adapt schema behavior: `optional`, `nullable`, `default`, `transform`, `pipeline`.
Use them to encode lifecycle decisions explicitly: missing values, null handling, fallback values, and conversion/validation stages.
Do not over-wrap fields when a plain schema is enough; excessive wrappers can hide intent and reduce debuggability.
