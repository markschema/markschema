# Docs App (`@markschema/docs`)

VitePress documentation app for `mdshape`.

## Commands

From repo root:

```bash
npm run docs:dev
npm run docs:build
npm run docs:preview
npm run docs:check
```

From this workspace:

```bash
npm run dev
npm run build
npm run preview
npm run check-quality
```

## Structure

- `docs/`: VitePress content and site config
- `scripts/`: docs quality checks (links + semantics)
